The system consists of a ceiling fan mounted on a horizontal rail, allowing the fan to move from one position to another along the rail. A small motor mechanism can be used to drive the fan assembly along the rail. The fan can therefore cover a wider area compared with a conventional fixed ceiling fan. Limit switches or sensors can be added at both ends to control the movement and prevent the fan from moving beyond the rail. The system can be controlled using an Arduino for automatic movement and fan operation.

Main components:

Arduino
DC/gear motor for rail movement
Ceiling fan/DC fan
Rail and sliding mechanism
Motor driver
Limit switches
Power supply
ON/OFF switches
